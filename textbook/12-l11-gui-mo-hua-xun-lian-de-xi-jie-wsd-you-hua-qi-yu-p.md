# L11｜规模化训练的细节：WSD、优化器与 μP

> Spring 2026 · 中文教材（含 Transcript 对照补遗）。主要依据用户提供的 `lecture-11.txt`，并结合[官方 PDF](https://github.com/stanford-cs336/lectures/blob/de53a9f979a6ee35f7d13a5e1aadee5ea1afc58e/lecture_11.pdf)。 时间定位：00:05–约 30:03 公开配方与 WSD；35:02–55:02 优化器；60:02–76:55 μP。 课件重点页：8–24、30–43、46–57（PDF 页码从 1 开始）。正文按知识逻辑重组，不是逐字翻译；“补充理解”与教学算例为作者解释。未逐句对照录音。

## 1. 理论曲线怎样落到真实训练

上一讲给出“拟合小实验，再外推”的框架，实际执行却有三个难点：不同规模的学习率与 batch 可能不同；大量训练终点需要分别适配衰减计划；架构与优化器变化可能破坏原先规律。

本讲用 MiniCPM、DeepSeek 等公开研究作案例。应该学习它们怎样设计实验和检查假设，而不是照抄某个学习率数字。数字只有在参数化、优化器、batch 定义和训练长度一致时才有意义。

## 2. 两条超参数迁移路线

第一条路线直接测量：在多个小规模上搜索学习率和 batch，拟合最优区域如何变化，再向大模型外推。第二条路线改变参数化，让跨宽度的最优超参数尽可能保持稳定，μP 就属于这一类。

这两条路线可以结合。即使使用 μP，也需要实验确认目标架构中的归一化、门控、embedding 与输出层实现遵守相应规则，不能认为“调用了初始化函数，所有东西都不需要调”。

## 3. 为什么训练中途停下不等于专门训练到那里

假设一个长训练的 cosine 学习率计划在 100B token 时才结束。在 10B 时取 checkpoint，此时学习率可能仍很高；另一个专门在 10B 结束的运行，已经完成了衰减。比较这两个终点，会把计划差异误算成数据量差异。

Warmup-Stable-Decay（WSD）先预热，再保持稳定学习率，最后做一段衰减。可以从稳定阶段不同 checkpoint 分叉出对应终点的 decay 分支，复用前面的训练。

**教学例子：** 稳定主干跑到 20B token，在 8B 和 16B 附近分别复制模型、优化器与随机状态，再运行各自的短衰减尾段。这样比从零训练每个终点更省，但仍需要为尾段付费，也必须明确最终 token 总量与可比较的计划比例。

不能直接把同一条稳定阶段轨迹上的所有损失点当成“完全收敛终点”。复用训练不等于取消终点优化。

## 4. 公平比较优化器的两个坐标轴

换优化器可能改变最优学习率、weight decay 和 batch。若只给新优化器旧的默认超参数，就可能错误地判定它不好。

另一个问题是训练 regime：一个方法可能在小模型、短训练时很好，在更多 token 或更大规模时收益缩小。比较应沿计算预算和数据/参数比例两个轴展开，并区分固定 FLOPs、固定时间和固定验证损失三个目标。

更低的验证损失若要多花一倍 optimizer 时间，可能不符合固定时间预算；反过来，更快的每步速度若需要更多步才能到目标损失，也不能直接称为更高效。

## 5. Muon 为什么把更新当矩阵看

Adam 主要逐坐标调整更新，Muon 对适用的矩阵参数，把动量更新作为一个整体矩阵处理。用 SVD 直觉，若 B=UΣVᵀ，正交化后的方向类似 UVᵀ，弱化不同奇异方向的尺度差异。

实际不需要每步做昂贵的完整 SVD，而可用有限次 Newton-Schulz 类矩阵迭代近似，实现中还涉及归一化、形状缩放与稳定化。embedding、输出层和向量参数通常要单独处理，不能把同一规则机械套到所有参数。

**补充理解：** 逐坐标方法像分别调每个旋钮，矩阵方法则关心整个线性变换在不同方向上的作用。但“方向更均衡”是直觉，不代表对任何任务都最优。

## 6. μP 首先想保持什么

宽度增加时，希望：初始化后单个激活的量级保持 O(1)，一次更新导致的激活变化也保持 O(1)。否则模型加宽时，信号可能爆炸、消失，或更新小到几乎不学特征。

一个简化推导：若 y=Σw_i x_i，输入近似独立、零均值、方差约 1，fan-in=n，则 ​Var(y)≈n·Var(w)。要让 Var(y) 稳定，可从 Var(w)≈1/n 出发。这个推导解释初始化为什么要依赖宽度。

但“初始化稳定”还不足以保证“更新稳定”。梯度与优化器的尺度也随宽度改变，μP 进一步安排不同类型参数的学习率和缩放。输出层、输入层和隐藏层的规则不一定相同，SGD 与 Adam 的规则也不完全相同。

这里不给出一个假装适用于所有 Transformer 的统一学习率公式；课件中的线性网络与谱范数推导是简化情形，完整结构需要对应的参数化规则。

## 7. 如何实际检查迁移是否成立

选取几个宽度，固定其他主要条件，画学习率—验证损失曲线。如果最优区域对齐，才获得当前实验范围内的迁移证据。还应检查激活、梯度和更新量级，不要只看一条最终损失。

课堂讨论的实证边界包括归一化增益、优化器变化和强 weight decay 等。它们提醒我们：理论通常在明确假设下成立，现代模型的细节可能需要额外修正。

## 8. 一份可执行的规模化决策流程

先确定架构与数据分布，再选参数化和优化器；用小规模确定宽度变化下的学习率与 batch；设计 WSD 或其他可比较的终点；拟合预算分配；最后用更大保留点验证。若外推失败，先定位 regime 或实现变化，而不是直接给幂律再加一个自由参数。

## 深入算例与补充理解

### 宽度变化为什么会改变更新意义

同样写 `W -= lr * grad`，每个元素的更新很小，不代表整个矩阵对隐藏状态的影响小。矩阵有越来越多元素，更新方向也可能高度相关，最终 `ΔW @ h` 的规模会随宽度变化。

所以 μP 关心的是函数与特征变化的尺度，而不仅是参数元素的标准差。检查参数 histogram 不够，还要检查同一输入在一步更新前后隐藏表示与输出的变化。

### 设计一个学习率迁移实验

选择宽度 d、2d、4d，在一致的数据、目标 token 数与参数化规则下扫描对数间隔学习率。比较每个宽度的最优区间，同时记录是否出现不稳定。为了避免一次随机运行误导，可以在少数候选点重复种子。

如果小宽度最优 10⁻³、大宽度最优 10⁻⁴，说明直接复制学习率没有迁移；若采用某参数化后谷底大致对齐，也只能说明当前深度、组件与优化器范围内成立。接着改变深度，还需要另一次检验。

### WSD 复用时要恢复哪些状态

分叉 checkpoint 不仅要恢复模型权重，还要考虑 optimizer state、学习率进度、数据迭代位置和随机数状态。只加载权重然后重建 Adam，会改变优化过程，不能称为严格复用同一训练轨迹。

此外，分叉出的 decay 段会消耗额外样本。进行成本核算时，主干计算不能既在所有分支中重复计费，又在其他地方完全忽略；分别报告总研究费用与每个最终模型的有效训练预算，更容易解释。

### 优化器比较不应只有一张最优曲线

至少保留几个学习率点，观察最优点附近是否宽阔、是否对 batch 和 seed 敏感。一个最优值很低却频繁发散的方法，在昂贵训练中可能风险更高。还要看 wall-clock：更好的每步样本效率可能需要昂贵预处理或通信。

所谓“更容易调参”是一个可研究的性质：它关乎最优区域宽度、迁移误差和失败概率。把这些记录下来，比只报告赢家的最终 loss 更有工程价值。

## 9. 自测

- 为什么比较 cosine 中途 checkpoint 与完成 decay 的短运行不公平？
- 为何 Adam 和 Muon 不能只共用同一个学习率做一次比较？
- 初始化方差按 1/n 缩放，是否意味着训练中的激活永远稳定？
- 一个拟合在训练 token 很少时有效，为什么到长训练可能失效？

**参考思路：** 终点优化、更新尺度、数据重复和训练阶段都可能发生变化；“迁移成功”应当是需要测量的事实。

### 公开配方比较的具体结论（00:00–约 39:00）

MiniCPM 的思路是通过分层初始化、缩放和学习率规则，使不同宽度的最优学习率更接近，再单独研究 batch 与目标 loss 的关系；DeepSeek 的例子则直接扫描学习率/batch，拟合其最佳区域随预算的变化。Qwen 等后续报告沿用类似流程，MoE 还需扫描稀疏度。不同报告得到不同指数，可能来自数据、参数计数与配方，不能只看作者给出的幂指数就认定是通用规律。

课堂介绍的 StepFun 扫描特别提醒：batch 的最佳值可能更随训练数据量变化，学习率同时受 batch、模型大小和数据量影响。数据分布改变也会移动最优点；这些式子提供起点，不能替代新结构上的验证。Llama 从上游 log-loss 映射到下游准确率的 sigmoid 只是近似，课堂也指出某些点系统性偏离。后训练的 scaling 规律仍更不确定，不能直接把预训练配方搬过去。

WSD 的稳定主干可从不同 checkpoint 分叉出 decay；课堂常举约末段 10% 衰减的示例，这是配方选择而非必需比例。不能先完成 decay，再假装直接继续同一条恒定学习率主干。充分调参的 cosine 仍可能略好，WSD 的重要收益是研究阶段复用成本与终点灵活性。

### 优化器成功与“证明更优”是两件事（约 39:00–57:00）

课堂展示小规模 speedrun 上 Muon 的收益，也展示随计算规模增大而收益缩小的实验。比较还必须扫描 token/参数比，避免只在短训练、过参数化区间下判断。某些新配方在小规模曲线很好，却在更大规模偏离或发散，这类失败是 scaling 验证要捕捉的核心证据。

Muon 的矩阵动量经近似正交化，意图调整奇异方向的相对尺度；有限 Newton–Schulz 步不等于精确 SVD。矩形矩阵的形状缩放和不适合该处理的向量/embedding 参数要单独安排。Kimi K2 的成功只证明采用相应稳定化的 Muon 配方能用于该规模，不能在缺少匹配 Adam 对照时证明它在该规模一定优于 Adam。

### μP 推导里哪些是假设（约 57:00–结尾）

宽度极限中，单坐标激活 O(1) 对应整层向量范数约 O(√宽度)，二者不能混写。课堂从初始化稳定、一步特征变化非消失两个目标出发，在简化深线性网络、单样本 SGD 和对齐/范数近似下讨论权重算子范数与更新尺度，再推导层间 fan-in/fan-out 规则。这是帮助理解的量级推导，不是对任意现代 Transformer 的严格证明；宽度变大而特征更新消失则接近课堂对比的 lazy/kernel 风格极限。

具体学习率乘数随参数类别和优化器不同，不能从 SGD 的 rank-one 更新直接推出 Adam/Muon 的全部规则。课堂的压力测试还提到可学习归一化增益、符号类优化器和强 weight decay 等可能破坏迁移；SwiGLU/RMSNorm 等超出最简推导的组件则需要实测，不能仅凭理论未覆盖就判定必然失败。本讲续行与公式口述尚需再次对照，不能从前一轮提取文本断定原始字幕缺句。
