# 开始之前：符号、单位与先修知识

## 本书怎样区分三种内容

正文从问题出发解释机制；教学算例用小数值把计算过程展开，补充类比帮助建立直觉。类比不代替严格证明，公式与实验结论应结合各自条件理解。需要深入查阅时，可以使用章节末尾的参考资料。

## 先会读张量形状

`X[B,T,d]` 表示三维数组：B 条样本，每条 T 个位置，每个位置 d 个数。元素总数是 B×T×d。维度名字是语义标记，不会使数据凭空复制。检查一个运算，先确定输入输出形状，再确定沿哪一维归约。

二维矩阵 A[m,k] 乘 B[k,n]，结果是 C[m,n]。每个输出元素是长度 k 的点积。转置交换行列，外积把两个向量组合成矩阵，逐元素乘法则要求维度可匹配或广播；三者不可混用。

## 常用符号

| 符号 | 含义 | 容易混淆处 |
| --- | --- | --- |
| B | batch 或并发请求数 | microbatch 与全局 batch 需另说明 |
| T、S | 序列/历史长度 | 推理章节会分别定义 |
| d | 模型隐藏宽度 | 不是参数总数 |
| h、h_kv | Query head 与 KV head 数 | GQA 中二者不同 |
| d_h | 每个 head 的维度 | 常见 h·d_h=d，并非数学必要条件 |
| f | MLP 中间宽度 | 普通 MLP 与门控 MLP 计数不同 |
| L | 层数；部分公式中为 loss | 根据章节语境区分 |
| N | 参数量 | MoE 区分总参数与激活参数 |
| D | 训练 token 总量 | 不等于独立 token 数 |
| C | 计算预算 | 明确是否包括研究试验与推理 |
| P、W | 计算吞吐、带宽 | 单位分别为 FLOP/s、byte/s |

## 概率、对数与损失

概率在 0 到 1 之间；自然对数 log p 小于等于 0，因此负对数损失非负。独立/条件概率的连乘，取 log 后成为求和。softmax 把实数 logits 变成概率，不能把 logits 当作已经归一化的概率。

梯度告诉我们某个变量微小变化怎样影响损失。最小化损失通常沿负梯度方向更新；最大化奖励则沿奖励梯度方向更新。代码里常把“最大化目标”写成“最小化它的负数”，阅读 RL 公式时要确认符号约定。

## 单位与估算

1 byte=8 bit；GB 通常为 10⁹ 字节，GiB 为 2³⁰ 字节。容量是 byte，带宽是 byte/s，二者不能互换。FLOPs 是工作量，FLOP/s 是执行速度。并非所有比较、指数运算和专用指令在统计中都有统一计数，必须说明口径。

粗估的价值是判断数量级和瓶颈，而不是给出虚假的精确承诺。实际实验需要记录设备、软件、dtype、形状、计时范围、预热、重复次数和误差。

## 自学时的四步

先用自己的话讲机制，再写出形状与单位，然后手算一个小例子，最后寻找一个会失败的边界条件。例如学 softmax 时，不只测随机数，还测大数、全相同、mask 与空有效行；学通信时，不只看结果，还检查每张卡的责任和更新时机。
