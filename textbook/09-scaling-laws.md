# L09｜Scaling laws：把小实验变成大模型决策

> Spring 2026 · 中文教材（含 Transcript 对照补遗）。主要依据用户提供的 `lecture-09.txt`，并结合[官方 PDF](https://github.com/stanford-cs336/lectures/blob/de53a9f979a6ee35f7d13a5e1aadee5ea1afc58e/lecture_09.pdf)。 时间定位：00:05–约 30:00 数据幂律；35:01–50:00 模型与超参数；55:01–77:47 预算分配。 课件重点页：15–26、35–45、47–54（PDF 页码从 1 开始）。正文按知识逻辑重组，不是逐字翻译；“补充理解”与教学算例为作者解释。未逐句对照录音。

## 1. 为什么不能凭感觉选择模型大小

给定相同训练计算预算，大模型每个 token 更贵，只能看到较少 token；小模型可以看更多数据，但容量可能不足。Scaling laws 希望用较小实验描述这种折中，减少在大规模训练上试错。

它是一种经验预测模型。理论泛化界往往提供上界，而这里希望预测实际会测到的损失。二者都与样本复杂度有关，但不能把拟合曲线当成严格保证。

## 2. 幂律与不可约损失

常用数据拟合形式为：

$$
L(D)=E+A D^{-\beta},\qquad A,\beta>0.
$$

E 是该模型假设中的损失底部，D 是数据量。若减去正确的 E，再画 log(L−E) 对 logD，就得到斜率 −β 的直线。

不减 E 也可能在有限范围看起来近似直线，但斜率会受区间影响。一个窄范围中的直线不足以证明远距离幂律外推，因为许多平滑函数在小区间都像直线。

课堂用均值估计作直觉：独立样本均值的均方误差为 ​σ²/n，本身就是幂律。神经网络的指数却不能只靠这个例子推出；数据结构、任务、模型与训练过程都会改变表现。

## 3. 共同拟合参数与数据

一个有用的简化形式是：

$$
L(N,D)=E+A N^{-\alpha}+B D^{-\beta}.
$$

N 是参数量，D 是训练 token 数。第一项描述模型容量不足，第二项描述数据不足；这是建模假设，不是损失必然能被物理拆成互不影响的两部分。

给定 (C\approx6ND)，有 (D=C/(6N))。代入并对 N 求导，在内部最优点得到：

$$
\alpha A N^{-\alpha}=\beta B D^{-\beta}.
$$

解出的规模关系为：

$$
N_*\propto C^{\beta/(\alpha+\beta)},\qquad D_*\propto C^{\alpha/(\alpha+\beta)}.
$$

如果两个指数接近，预算增加时，参数和数据都大致按平方根增长。这个推导比死记一个 token/parameter 比值更重要，因为它让你知道结论来自什么假设。

## 4. 三种获得计算最优曲线的方法

**训练轨迹包络：** 从很多训练运行的损失轨迹中，取给定计算预算下的最佳点。要注意学习率计划是否适合该终点，不能认为一次长训练中的中途点就等于专门训练到那里。

**IsoFLOPs：** 固定预算 C，改变 N，并相应调整 D，得到同预算损失曲线，再寻找最优点。对多个 C 重复，拟合最优 N 与 C 的关系。

**联合参数拟合：** 在 N/D 网格上训练，直接拟合 E、A、B、α、β。它利用数据更多，但优化和参数辨识也更敏感；损失函数、初始值、离群点都会影响结果。

## 5. Kaplan 与 Chinchilla 为什么不同

课堂借这段研究史提醒：参数是否计 embedding、warmup 占比、batch 大小和优化是否充分，都能改变拟合。Kaplan 风格的早期结论更偏向随预算迅速增加模型大小；Chinchilla 则强调数据与参数更均衡增长。

文字稿中口头陈述指数时发生过交换，课件给出的早期分配是 N 随 C 的指数约 0.73、D 约 0.27。本教材按课件校对这一方向，不照抄口误。

“约 20 token/参数”是某些设置下的经验数量级，不是永远最优的定律。训练数据质量、架构、预算范围和推理使用量变化，最优点也会移动。

## 6. 训练最优不等于生命周期最优

如果模型将被调用很多次，较小模型训练更多 token，可能花更多一次性训练费用，却节省大量后续推理费用。此时目标应包含：

$$
C_{total}=C_{train}+M\,C_{infer},
$$

M 是预计使用量。所谓 overtraining 往往只是“超过训练预算最优的 token/参数比”，不等于统计意义上开始过拟合。验证损失仍可能继续下降。

**补充理解：** 买车时不能只看购车价，还要看跑多少公里和每公里成本。模型规模选择同样需要使用场景。

## 7. 数据重复、batch 与学习率

重复一份语料会增加处理 token 数，却不等于增加同样多的独立信息；需要区分 seen tokens 与 unique tokens。过滤后质量提高，也可能因数据过少而重复过多，因此最优筛选强度会随计算预算改变。

batch 变大可以提升并行效率，但超过某个范围后，每增加样本带来的优化收益递减。critical batch 不是所有任务共享的数字，甚至可能随目标损失与训练阶段变化。学习率也不能不加分析地从小模型照搬到大模型；μP 等参数化方法试图改善这类迁移。

## 8. 一份可信的拟合实验应该留下什么

保留原始运行点、参数计数规则、实际 token 数、精度和模型结构；留出较大规模点检验外推，检查残差，而不是只报告高 R²。对数据量或模型大小特别小的区间，确认是否仍处在想要的同一训练 regime。

## 深入算例与补充理解

### 用一条简化曲线看预算最优点

教学假设 α=β=1、A=B=1、E=0，且为简化把成本写成 C=ND=100。此时损失 L=1/N+1/D。N=1、D=100 时 L=1.01；N=10、D=10 时 L=0.2；N=100、D=1 时又回到 1.01。

这说明固定预算下，两种不足需要平衡。该算例不是现实语言模型指数，却把 IsoFLOPs 曲线为何呈现一个低谷解释清楚：任何一边走得太极端，另一边就不足。

把 C 改为 400，最优点 N=D=20，损失降到 0.1。相同的减半损失需要四倍预算，体现边际收益递减。真实指数通常不同，但“更好需要越来越多资源”的解释方式相同。

### 拟合误差可能来自哪里

假如小模型损失明显偏离曲线，不应立即删点。可能是模型过小，embedding 占比改变；也可能是 batch、warmup 对小模型不合适，训练尚未进入相同 regime；还可能是数据样本数太少造成方差。

应保存每个点的训练曲线和环境，检查是否异常结束、是否用了不同 tokenizer 或数据处理版本。拟合看上去更漂亮，不是移除数据的充分理由。

### 一个常见的错误外推

若小实验从 1B 独立 token 中只取 10M，某个优质来源占一半，看起来很好；大模型按同样比例训练到 100B，却要把那个来源重复很多次。即便公式写对，实验已经换了数据重复 regime。

这不是“Scaling laws 失效所以没用”，而是自变量 D 没有包含独立信息、重复次数和来源构成。扩展模型之前，先确定旧规律的定义域。

### 怎样表达预测的不确定性

可以拟合多个合理函数形式、改变训练子集或初始化，并观察外推范围；也可以留出最大的若干运行，先预测再揭示真实值。重点是检验“未见规模”的误差，而非只检查训练点拟合。

做预算决策时，最优曲线附近往往比较平坦。若 N 相差 20% 而预测损失几乎相同，系统吞吐、部署成本和风险可能比追求一个精确最优点更重要。报告一个稳健区间，通常比报出十位有效数字更诚实。

## 9. 自测

- α=β 时，把预算扩大四倍，简化模型预测 N 和 D 各扩大多少？
- 为什么固定总 token 数比较模型，和固定 FLOPs 比较模型，回答的是不同问题？
- 重复语料十遍能否按十倍独立数据代入旧公式？
- 若一个小模型更易部署，你应该优化训练成本还是总生命周期成本？

**参考思路：** 第一问各两倍；其次必须控制资源口径、独立信息量和实际部署使用量。

## Transcript 对照补遗

### 数据 scaling 被初版省略的分支（00:00–约 30:00）

课堂把 scaling 放回样本复杂度和经验学习曲线的历史中，而不是把它当成现代 LLM 才有的发现。均值估计的 MSE=σ²/n 是严格例子；非参数回归用于说明更慢的幂律可能来自函数复杂度，但口述 `n^(−1/d)` 不能当作任意光滑函数的通用最优率，严格速率还依赖光滑度、维度、噪声与损失。更不能仅凭一个神经网络指数反推出“真实内在维度就是 10”。

数据混合也能纳入小规模实验：对新闻、百科等比例做扫描，观察各来源评估，再决定是否拟合混合规律。课堂也明确提到某些研究发现“选小规模最好的比例直接放大”已有效，不一定非要加一条复杂 scaling law。很多改动可能主要改变截距，斜率相近；这是一类实验现象，不能预先假定任何配方排序都保持不变。

课堂举例某研究中前约四个 epoch 的重复损失较小，之后明显不如新数据；这是数据与配方相关观察，不能承诺任意语料重复四遍都无损。无限计算、固定数据的讨论还提到正则化和集成的收益，以及模型/epoch 增大后的递减。更强过滤在小预算有利，大预算则可能因独立数据不足而应放宽过滤。窄区间里多种函数都像直线，要检查坐标是否真正取了 log，不能凭图形认定幂律。

### Critical batch 的测量定义（约 39:00–51:00）

固定目标损失，对不同 batch B 测达到目标所需步数 S 和样本量 E=BS。课堂采用的经验权衡可写为 `(S/S_min−1)(E/E_min−1)=1`，其平衡尺度为 `B_crit=E_min/S_min`。在这个拟合模型下，B=B_crit 时 S≈2S_min、E≈2E_min，而不是同时达到两个独立最小值。梯度协方差与平均梯度范数之比又可作噪声尺度估计，仍有近似条件。

临界 batch 可以随目标损失降低而增加，因而也成为 scaling 的对象。学习率有两条路线：拟合最佳值随宽度的变化，或用 μP 等参数化使最优值更可迁移。`1/宽度` 只是某些设定的规则，优化器、层类型和参数化改变后不能照搬。

### 上游、下游与 Chinchilla 分歧（约 30:00–39:00；51:00–结尾）

比较结构/优化器，要检查 scaling 曲线在目标范围的排序和斜率，而非只挑一个点。MoE 又要把总参数、激活参数和稀疏度分开。低 perplexity 通常有价值，却不能保证任意下游任务排序相同；课堂特意给出排序不一致的例子。大评估集使某些 loss 点方差较低，不等于所有实验都可不做种子重复或误差检查，也不能因为单遍训练就放弃验证集。

Kaplan–Chinchilla 的差异不是一句“早期论文错了”即可解释：输出投影/embedding 的计数、小计算区间、warmup 长度和小模型 batch 设置都可能改变估计。固定长 warmup 使短运行大部分处于 warmup，会扭曲最优点；多变量曲面拟合还可能欠拟合或陷入不佳优化。课堂介绍对 Chinchilla 第三种拟合方式的后续重拟合，使其更接近其他方法，说明连曲线拟合本身也需要验收。

Scaling 是对特定训练配方的预测，不是数学保证的性能下界；差配方也能产生整齐但无用的曲线。IsoFLOPs 的价值是把预算控制清楚，再扫描自由度。服务规模大时应把训练、研发、推理总成本一起考虑，不能只优化“20 token/参数”。
